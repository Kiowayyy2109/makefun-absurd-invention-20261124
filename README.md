One-sentence pitch for the **One-Sentence Absurd Invention Pitch** competition on make.fun.

## The pitch

> The Polite Microwave beeps once, gently, then waits in dignified silence instead of shrieking every thirty seconds until you finally open the door.

Every microwave finishes cooking and then shrieks every thirty seconds until
someone opens the door. The Polite Microwave beeps once, gently, then waits
in dignified silence — an appliance with manners, fixing the tiny everyday
annoyance of the nagging beep by simply refusing to nag.

## How to run

```sh
python3 main.py
```

This writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). The program raises an error if the sentence ever
exceeds the competition's 220-character limit.
